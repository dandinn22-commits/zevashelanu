הצבע שלנו - דף נחיתה
======================

מה יש בתיקייה:
- index.html          → קובץ האתר הראשי
- thank-you.html      → דף התודה שמופיע אחרי מילוי הטופס
- accessibility.html  → דף הצהרת הנגישות (מקושר מהפוטר)
- assets/             → תיקיית התמונות (לוגו + תמונת רקע)

איך מעלים לדומיין:
------------------

אפשרות 1 - ניהול אתר עם File Manager / cPanel:
1. נכנסים לניהול האחסון (cPanel, Hostinger, וכו') ופותחים את File Manager.
2. נכנסים לתיקיית public_html (או www / httpdocs, תלוי בספק).
3. גוררים את כל תוכן התיקייה הזו (index.html + תיקיית assets) לתוך public_html.
4. חשוב: לא לגרור את התיקייה "site" עצמה, אלא את מה שבתוכה.
5. גולשים לכתובת הדומיין - האתר אמור לעלות מיד.

אפשרות 2 - שירותי אחסון חינמיים (Netlify, Vercel וכו'):
1. נכנסים לאתר כמו netlify.com/drop.
2. גוררים את כל התיקייה הזו (site) ישירות לדף.
3. מקבלים כתובת זמנית, ואם רוצים - מחברים אליה את הדומיין שלכם בהגדרות.

אפשרות 3 - FTP:
1. מתחברים לשרת עם תוכנת FTP (למשל FileZilla) עם הפרטים שקיבלתם מהספק.
2. מעלים את index.html ואת תיקיית assets לתוך public_html.
